# Guess the Number Game (SF Homework)

## Задание
Реализуйте игру "Угадай число" на Python.

### Правила
- Компьютер загадывает число от 1 до 100.
- Игрок угадывает число.
- После каждой попытки выводить подсказку: "Загаданное число больше" или "Меньше".
- Показывать количество попыток.

### Требования
- Код должен быть чистым и понятным.
- Использовать циклы, условия, ввод/вывод.

## Как запустить
python guess_number.py

### Пример
$ python guess_number.py
